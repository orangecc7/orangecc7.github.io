# Academic homepage design

Refine the existing academic homepage toward editorial minimalism: bright orange details, warm whites, precise type, and visible research. Preserve the top navigation, profile sidebar, About → News → Selected Publications → Education → Projects order, factual copy, links, and figure interactions.

- **Layout:** use the same spacing system as the refined ccandtt homepage: 1,180px maximum width, a 196px profile column, a 28px base gutter, and 28px outer padding. On wide screens the profile and Homepage brand move left by up to 24px, giving a 52px visible profile/content gap while preserving the main text position. The shared `--ui-unit` is fixed at 1px; pointer-driven windows do not reduce reading scale. At 1100px and below the sidebar is 176px with a 24px gap; 701–960px uses 156px and 20px. At 700px and below the profile precedes the main content. Publication figures use 236 × 166px frames and a 24px text gap, shrinking to 190px columns below 1100px. Publications stack at 580px and below, and at 701–860px to preserve the larger reading size in the sidebar layout. Navigation and main content share column starts; the Homepage brand follows the profile offset. These overrides live in `assets/css/layout.css`, loaded after `profile.css` with a content-version query.
- **Typography:** retain `"Trebuchet MS", Helvetica, sans-serif` and the greeting-only `"Comic Sans MS", "Comic Sans", cursive`. Match the refined ccandtt semantic sizes: body 16px, greeting 40px (34px on stacked layouts), section 23px, Selected Publications 25px, research direction 20px, paper and institution titles 18px, profile name 24px, project title 26px, supporting text 15px, small text 14px, metadata 13px and labels 12px. Desktop navigation uses 15px and narrow navigation 14px. Introduction measure is 850px, with natural left alignment and 1.8 line height. Regular prose retains the existing softer near-black and dark-mode equivalent; semantic emphasis uses 700 weight. Browser zoom, viewport metadata and operating-system scaling remain native. No unlicensed font files are bundled.
- **Color:** brand orange `#ff7a1a`, hover/display orange `#f05a00`, pale orange `#fff4e8` and `#ffe2c2`; text `#20242a`, secondary `#68707c`, decorative muted `#98a0aa`, border `#ece8e3`, white page and warm `#fcfbf9` surfaces. Small orange text uses `#c34d00` for legibility; decorative gray is not used for informational text. The advisor name link uses academic blue `#1a5fb4`, a darker blue `#124882` on hover, and lighter blue equivalents in dark mode; visited links retain blue. Dark mode has corresponding warm semantic values. Legacy variables alias the semantic tokens.
- **Rhythm:** a shared 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px spacing scale. Hero after-space is 48px, News 32px and research 64px, matching the refined ccandtt page. Profile groups use 24px spacing; the role and affiliation add 12px and 8px top space respectively. Metadata and descriptions retain the existing compact gaps.
- **Profile:** original circular frame remains, enlarged to 176px on desktop and capped by the sidebar width; the phone frame remains 96px; the portrait is shown at 1.02× with 48% horizontal object positioning, a 6% downward translation, and a top transform anchor so the head is smaller and the subject sits lower and to the right. The same source image fills the crop background to avoid an empty strip at the top; a faint orange outline gains color on hover. The sidebar identity reads `Undergraduate` and the learning interest reads `World Models(learning)`. Profile groups use 24-unit spacing, secondary identity stays orange, and Research is a small uppercase text label above the existing plain-text interests. The favicon uses the author-provided orange illustration copied to `assets/icons/orange.png` and stays independent of the portrait. All imported icons live inside this repository, without a dependency on the sibling `icons/` folder. The sidebar learning topic matches the type and color of the other interests; the complete Research interests remain visible when the mobile profile stacks; Email, WeChat, and QQ appear as concise linked labels, with account details kept in their destinations. WeChat copies `orange_ychen` and QQ copies `3132454640`; both use a white, dark-orange-text capsule with a matching 1px dark-orange (`#c34d00`) border positioned 10px to the right of the clicked link, visible for 0.5 seconds before fading out over 180ms. Success capsules are 20px high (12px text, 16px line height, 1px vertical padding, and 1px borders). A single white-filled SVG path draws the capsule and small left pointer with one continuous 1px dark-orange outline, avoiding overlapping borders or seams. It follows the current bubble dimensions, including multiline manual-copy messages, and slides gently to the right while disappearing. The fixed overlay does not shift sidebar content. Clipboard failures reveal a selectable account for 8 seconds. Repeated clicks replace the single bubble and reset its timer; keyboard activation, polite status announcements, dark mode, and reduced motion remain supported.
- **News:** white, borderless list container; tabular years occupy a fixed column. Rows have pale dividers and a very light orange hover/focus background. Paper names and important status use restrained orange text. No enclosing card.
- **Publications:** original complete diagrams in light 236 × 166px image frames, black bold titles, orange text venues, secondary descriptions and role labels, and plain Paper / Code links with local SVG arrows. Pointer hover moves an entry up 2px and warms its image border; no shadow or card surface.
- **Sections and icons:** use the author's six original PNGs in `assets/icons/headings/` for News, Selected Publications, Education, Projects, AIGC Detection, and World Models. Crop only fully transparent outer margins, preserving visible pixels and colors without resampling. Render them proportionally inside a 24px frame with `object-fit: contain`, no border, background, or shadow; their longest visible dimension now fills that frame. LLM Safety keeps the original red mischievous horned devil in `_includes/icons/headings/llm-safety.svg`, with its scoped red palette. Decorative images have empty alt text beside visible titles. Contact, resource, theme, and dialog icons retain only the bundled Phosphor Fill SVGs that are still used. Previous heading illustrations and unused Phosphor variants are removed. Selected Publications uses 25px; AIGC Detection, LLM Safety, and World Models share the same 20px bold h3 heading with an 8px inset, 24px icon, and 10px gap. World Models is a third peer research group within Selected Publications; its learning description appears below the heading, aligned with the title text. Only adjacent research groups gain a pale divider, with no separate cards. Resource icons remain 14px, and text navigation has a 2px moving orange underline.
- **Education:** retain the chronological list and official university links. Each entry presents the institution with a small abbreviation, degree and major on the next line, then the school in secondary text. JNU lists Information and Computing Science / School of Mathematics and Data Science; BUPT lists Computer Science and Technology / School of Computer Science. A 102px date/status column aligns with the institution on desktop, with a pale divider between entries. Below 580px, date and status share one line above the full-width details to keep long names readable. Dates and current/planned study status remain explicit.
- **Projects:** VoicePrint retains one original Home screen screenshot in a 180px area with a single light image border, the existing description, tech stack, and repository link. The screenshot and description share a tighter 32px gap; the description aligns toward the top, with no enclosing gallery card. The visible Home caption is omitted; the original screenshot link and accessible name remain. Original pixels are unchanged; website copy remains English.
- **Interaction:** 180ms ease-out transitions for links, navigation indicator, portrait, and publication hover. Native figure dialog, keyboard focus, loading/error feedback, theme persistence, and original links remain intact. Reduced-motion preferences disable authored transitions and smooth scrolling; coarse-pointer contact links, navigation, theme controls, and paper/project links retain a 44px minimum height after responsive overrides. Narrow navigation remains natively horizontally scrollable. Native touch, keyboard, clipboard notices, and figure dialogs share the same behavior across layouts.
- **Constraints:** no new cards, gradients, glass effects, large shadows, entry animations, or unrequested content deletion. The introduction keyword row and the open-source-tools sentence are omitted at the author’s request. JNU and the get-in-touch invitation are plain text. The greeting reads “Hi, I'm Orange🍊.” in Comic Sans MS. Sidebar interests and the World Models learning description use the shared 15px supporting-text size; the World Models heading shares the 20px research-area hierarchy. Dates, planned study labels, and submission status remain unchanged.

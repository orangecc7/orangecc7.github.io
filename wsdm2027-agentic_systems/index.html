Overview

Agentic systems are transforming Web search, data analysis, and scientific discovery. Reliable deployment still faces challenges in grounding, memory, tool use, execution, and governance.

This workshop brings together database research, graph mining, and geometric learning to explore reliable, scalable, and accountable agentic systems. We focus on workflow optimization, consistent state management, graph-based memory and retrieval, Riemannian representations, and responsible self-improvement. Through invited talks, paper and demo presentations, and discussion, we aim to define a shared research agenda for the next generation of Web intelligence.

Call for Papers

Submission details to be announced.

We invite research papers, short or position papers, and demo contributions on the management of agentic systems. Topics include, but are not limited to:

  1. Workflow management

    declarative interfaces, execution and query optimization, resource allocation, checkpoints, and recovery.

  2. Persistent state and memory

    consistent updates, temporal knowledge, memory consolidation, and graph-based retrieval with traceable evidence.

  3. Multi-agent coordination

    shared knowledge, concurrent updates, communication graphs, task dependencies, and reliable tool use.

  4. Geometric representations and reasoning

    Riemannian and hyperbolic methods for hierarchical memory, relational structure, and retrieval.

  5. Scientific workflows and self-improvement

    hypothesis and experiment management, validation, reproducibility, and controlled adaptation.

  6. Evaluation and governance

    capability boundaries, failure analysis, provenance, access control, human oversight, and quality–cost trade-offs.
